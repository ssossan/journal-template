# ChatGPT Journal — 話すだけの日記

ChatGPTに話しかけるだけで、日記があなた専用の非公開GitHubリポジトリに
自動保存される仕組みです。

- 決まったフォームなし。「今日の日記」と話しかけて、あとは自由に話すだけ
- 「保存して」と言ったときだけ保存される。書かれるのは**あなたが話した内容だけ**
  (AIの解釈や推測は日記に混ざりません)
- 日記データはあなたのGitHubアカウントの**非公開リポジトリ**に、あなただけの
  所有物として残ります

セットアップは1回だけ。所要15〜20分です。

## 必要なもの

- **ChatGPTの有料プラン**(Plus以上)とスマホのChatGPTアプリ
- **GitHubアカウント**(無料。持っていない人はStep 1で作ります)
- セットアップ作業用のブラウザ(PC推奨。スマホのブラウザでも可能)

---

## Step 1. GitHubアカウントを作る(持っている人はStep 2へ)

GitHubは、ファイルを安全に保管・履歴管理できるサービスです。ここに日記が
保存されます。

1. ブラウザで [github.com](https://github.com) を開く
2. 「Sign up」を押す
3. メールアドレス、パスワード、ユーザー名(半角英数字。例: `taro123`)を入力
4. 届いた確認コードを入力して登録完了

ユーザー名は後で使うのでメモしておいてください。

## Step 2. このテンプレートへの招待を受ける

このテンプレートは非公開のため、招待された人だけが使えます。

1. あなたのGitHubユーザー名を配布者に伝える
2. 招待メール(またはGitHub上の通知)が届いたら「Accept invitation」を押す
3. このページ(テンプレートのリポジトリ)が開けるようになればOK

## Step 3. 自分の日記リポジトリを作る

「リポジトリ」はGitHub上のフォルダのようなものです。このテンプレートから
自分専用の日記リポジトリを1クリックで作れます。

1. このページの上部にある緑色の **「Use this template」** ボタンを押し、
   **「Create a new repository」** を選ぶ
2. **Repository name** に `my-journal` と入力(好きな名前でも可)
3. **必ず「Private」を選択する**(これを忘れると日記が全世界に公開されます)
4. **「Create repository」** を押す

これで `あなたのユーザー名/my-journal` という非公開リポジトリができました。

## Step 4. ChatGPTとGitHubを接続する

ChatGPTがあなたの日記リポジトリに読み書きできるようにします。

1. ChatGPTの **設定** を開き、**コネクター**(Connectors)から **GitHub** を選ぶ
2. 「接続」を押すと、GitHubの認証画面が開くのでログインして許可する
3. アクセスを許可するリポジトリを選ぶ画面では、**「Only select repositories」
   (選択したリポジトリのみ)** を選び、Step 3で作った日記リポジトリ
   **だけ** を選択する

※ 全リポジトリへのアクセスは許可しないでください。日記リポジトリだけで
動きます。

## Step 5. ChatGPTにProjectを作る

1. ChatGPTで新しい **Project** を作る(名前は「日記」など自由)
2. このリポジトリの
   [`setup/chatgpt-project-instructions.md`](setup/chatgpt-project-instructions.md)
   を開き、本文を**全部コピー**する
3. Projectの **Instructions**(指示)欄に貼り付ける
4. 貼り付けた本文の上のほうにある
   `YOUR_GITHUB_USERNAME/my-journal` を、**自分のユーザー名/リポジトリ名に
   書き換える**(例: `taro123/my-journal`)。その下の「↑ 必ず〜」の行は
   消してよい
5. 保存する

## Step 6. 最初の日記を書いてみる

1. Step 5のProjectの中で**新しいチャット**を開く
2. 「今日の日記」と送って、今日あったことを自由に話す(音声入力もおすすめ)
3. 話し終わったら **「保存して」** と送る
4. ChatGPTが保存結果(ファイルの場所など)を返したら、GitHubの自分の
   リポジトリを開き、`entries/` フォルダの中に今日の日付のファイルが
   できていることを確認する

ファイルができていればセットアップ完了です🎉

---

## 日々の使い方

- **Projectの中で**新しいチャットを開いて話す(Projectの外だと日記になりません)
- 朝・昼・夜と分けて話してOK。「保存して」と言うまでは書き込まれません
- 「短めで」と言えばサッと終わり、「深掘りしたい」と言えばじっくり聞いてくれます
- 過去の日記の訂正は「◯日の日記のここを訂正したい」と言えば、元の記録を
  消さずに訂正が追記されます
- 保存された日記は、GitHubのリポジトリでいつでも読み返せます

## 気をつけること

- **パスワードや暗証番号などの秘密情報を日記に話さない**でください
- 他人の氏名や連絡先など、書き残す必要のない個人情報は控えめに
- リポジトリがPrivateになっているか、最初に一度確認してください
  (リポジトリ名の横に「Private」と表示されていればOK)

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| 「保存できない」と言われる | Step 4のコネクター接続と、日記リポジトリが選択されているか |
| 保存したはずなのにファイルがない | ChatGPTの返答に「保存しました」とあるか。エラー表示の場合は内容を確認 |
| 日記と関係ない動きをする | Instructionsのリポジトリ名を自分のものに書き換えたか(Step 5-4) |
| Privateにし忘れた | リポジトリのSettings → 一番下のDanger Zone → Change visibility → Private |

## 仕組みが気になる人へ

- 日記はすべて `entries/年/月/日付.md` のテキストファイルで、持ち出し・
  バックアップ・引っ越しが自由にできます
- 各記録には保存日時などのメタデータが付き、後から黙って書き換えられない
  設計です(訂正は履歴が残る追記方式)
- Instructionsの更新版はこのテンプレートで配布します。たまに見に来て、
  新しくなっていたらStep 4の要領で貼り直してください
